猫は不調を隠す動物です。体調が悪くても普段どおりに振る舞おうとするため、飼い主が気づいた時には進行していることがあります。

そのぶん**行動の小さな変化が重要な手がかり**になります。この記事ではストレスのサインを整理します。

<VetNotice level="caution">
<p>ここに挙げる変化は、ストレスだけでなく体の不調でも現れます。「性格の問題」と片付けず、数日続く場合は獣医師にご相談ください。</p>
</VetNotice>

## 行動に出るサイン

### 隠れて出てこない

猫が安全な場所に退避するのは自然な行動ですが、**食事や排泄のときも出てこない**なら程度が違います。来客や工事など原因が明確なら一時的なことが多いものの、数日続くなら環境を見直してください。

### 過剰なグルーミング

同じ場所を舐め続け、毛が薄くなる状態です。猫は不安を感じるとグルーミングで落ち着こうとします。**脱毛が見られる段階では相当なストレス**か、皮膚の問題が背景にあります。

### 食欲の変化

食べない、逆に急に食べるようになる。どちらも変化です。とくに**猫が丸一日以上食べない状態は危険**とされており、肝臓への負担が問題になります。

### 攻撃的になる・よく鳴く

触ろうとすると怒る、夜中に鳴き続けるといった変化です。痛みがある場合にも同じ行動が出るため、**どこかを触ったときだけ嫌がる**なら体の問題を疑ってください。

## トイレに出るサイン

トイレは変化が見えやすい場所です。

- 回数が増えた、または減った
- トイレの外で排泄する
- 入ってもすぐ出てくる
- 砂をかけなくなった

**粗相はしつけの問題ではないことがほとんど**です。トイレ環境への不満か、体の不調が背景にあります。叱っても解決しません。

排尿の変化については[猫のおしっこの回数と量の目安](/articles/cat-urination-frequency/)で詳しく整理しています。

## よくある原因

| 原因 | 対処の方向 |
| --- | --- |
| 引っ越し・模様替え | 元の寝床やにおいのついた物を残す |
| 新しい同居猫・来客 | 隔離できる空間を確保する |
| トイレが汚れている | 掃除の頻度を上げる、数を増やす |
| 工事や雷などの音 | 静かな避難場所をつくる |
| 留守番が長い | 上下運動できる環境、見守りの手段 |
| 飼い主の生活リズムの変化 | 給餌時間だけでも一定に保つ |

猫は**変化そのものを嫌う**動物です。何かを良くしようとした模様替えが、猫にとってはストレスになることもあります。

## 環境を見直すときの優先順位

一度に全部変えると、かえって混乱させます。効果が出やすい順に試してください。

1. **トイレ** — 清潔さと数。頭数＋1が目安
2. **隠れ場所** — 誰にも邪魔されない空間が1つあるか
3. **高い場所** — 上から見下ろせる位置は猫にとって安心材料
4. **食事場所** — トイレや騒がしい場所から離れているか
5. **遊びの時間** — 1日5〜10分でも狩りに似た遊びを

このうち**トイレと隠れ場所の2つで解決することが多い**です。道具を買い足す前に、まずこの2つを確認してください。

## 受診を考える目安

<VetNotice level="emergency">
<p>次の状態は緊急性が高いため、環境を見直す前に動物病院へ連絡してください。</p>
<ul>
  <li>ぐったりして動かない、呼びかけへの反応が鈍い</li>
  <li>丸一日以上まったく食べていない</li>
  <li>トイレに行くのに排尿がない</li>
  <li>呼吸が苦しそう、口を開けて呼吸している</li>
</ul>
<p>猫が食べない状態が続くと肝臓に負担がかかるとされ、時間が経つほど対応が難しくなります。</p>
</VetNotice>

次の場合も、環境調整と並行して相談してください。

- 脱毛するほど舐め続けている
- 排泄の異常が2〜3日続く
- 急に攻撃的になった、触ると嫌がる場所がある

**「ストレスだろう」で様子を見るのが最も危険**です。同じ症状が体の病気で出ることは珍しくありません。

## まとめ

- 猫は不調を隠すため、**行動の変化が重要な手がかり**になる
- 行動・体・トイレの3方向で見る
- 粗相はしつけではなく、環境か体調の問題
- 環境を見直すなら**トイレと隠れ場所から**
- ストレスと決めつけず、続く変化は受診する
