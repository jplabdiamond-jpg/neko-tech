「猫は犬より手がかからないから安い」とよく言われます。毎月の固定費だけを見ればそのとおりですが、実際に飼い始めると**想定していなかった出費**が出てきます。

この記事では猫1匹あたりの費用を項目別に分解し、月額と年額を試算します。

## 結論：月7,000〜12,000円、年間で約10万〜15万円

内訳の目安はこうです。医療費を含まない平常時の固定費で、月7,000円前後が下限になります。

| 項目 | 月額の目安 |
| --- | --- |
| キャットフード | 3,000〜6,000円 |
| 猫砂 | 1,500〜3,000円 |
| ペットシーツ・消耗品 | 500〜1,500円 |
| おやつ・おもちゃ | 500〜1,500円 |
| 医療費（年間を月割り） | 1,500〜3,000円 |
| **合計** | **7,000〜15,000円** |

ここに保険に入る場合は月1,500〜3,000円程度が加わります。

## 固定費の中身

### キャットフード

最も差が出る項目です。市販のドライフードなら月3,000円程度ですが、原材料にこだわったフードや療法食になると倍以上になります。

ウェットフードを併用する場合も上がります。1食100〜200円のパウチを1日1回使うと、それだけで月3,000〜6,000円が追加されます。

### 猫砂

銘柄と消費量で変わります。鉱物系は安価で月1,500円程度、紙系やおから系は割高で月2,500〜3,000円になることもあります。

自動猫トイレを使う場合、専用砂が必要な機種だとここが跳ね上がります。本体価格だけで判断すると数年で差が出るため、[自動猫トイレの3年総額](/articles/auto-litter-box-total-cost/)で先に総額を計算しておくことをお勧めします。

### 医療費

平常時でも年1回のワクチンと健康診断で1〜2万円かかります。これを月割りすると1,000〜1,500円程度です。

ただし**これは何も起きなかった年の金額**です。実際には通院が発生する年があり、そこで一気に跳ね上がります。

## 初期費用も見ておく

迎えた月だけは別枠の出費があります。

| 項目 | 目安 |
| --- | --- |
| ケージ・トイレ・食器 | 15,000〜30,000円 |
| キャリーバッグ | 3,000〜8,000円 |
| 爪とぎ・ベッド | 3,000〜8,000円 |
| ワクチン（初年度2〜3回） | 8,000〜20,000円 |
| 避妊・去勢手術 | 20,000〜50,000円 |
| 譲渡費用・購入費用 | 0〜数十万円 |

避妊・去勢は自治体によって助成金が出る場合があるので、お住まいの地域の制度を確認してください。

初期費用の合計は、保護猫を迎える場合で**5万〜10万円程度**を見ておくと安心です。

## 見落としやすい出費

試算から漏れやすいものを挙げます。

- **家具・内装の買い替え** — 爪とぎでソファや壁紙が傷む。賃貸なら退去時の原状回復費用も
- **旅行時のペットホテル** — 1泊3,000〜5,000円。年に数回なら無視できない額に
- **季節の光熱費** — 留守番中もエアコンをつける場合、夏冬は月数千円の上乗せ
- **高齢期のケア** — シニアになると療法食や通院の頻度が上がる

特に最後の2つは、飼い始めの試算に入っていないことが多い項目です。

## 医療費は「平均」で考えないほうがいい

飼育費用で最も読みにくいのが医療費です。何もない年は年1万円台で済みますが、手術や継続的な通院が必要になると**1回で数万円から数十万円**になります。

平均値で予算を組むと、実際に必要になったときに備えがない状態になります。この性質があるため、医療費だけは「平均いくら」ではなく「最悪どれくらいか」で考えたほうが現実的です。

詳しい内訳は[猫の医療費はいくらかかるか](/articles/cat-medical-cost/)で整理しています。

## まとめ

- 平常時の固定費は**月7,000〜15,000円**、年間10万〜15万円
- 初期費用は保護猫で**5万〜10万円程度**
- 猫砂とフードは選び方で倍近く変わる
- **医療費だけは平均では読めない**。備え方を別に考える必要がある

金額を把握したうえで迎えれば、途中で苦しくなる事態は避けられます。逆に「安いらしい」という印象だけで始めると、医療費が発生した時点で判断を迫られることになります。

※ 本記事の金額は2026年11月時点の一般的な価格帯をもとにした試算です。地域や選ぶ商品によって変わります。
