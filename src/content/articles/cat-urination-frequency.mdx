猫は泌尿器のトラブルが非常に多い動物です。しかも初期はほとんど症状が出ないため、飼い主が気づいた時には進行していることが珍しくありません。

逆に言えば、**毎日の排尿を見ているだけで異変に気づける**可能性が高い動物でもあります。この記事では回数と量の目安、記録のとり方、受診の判断を整理します。

## 排尿回数と量の一般的な目安

健康な成猫のおおよその目安は次のとおりです。あくまで一般的な範囲で、個体差・食事・季節によって変わります。

| 項目 | 一般的な目安 |
| --- | --- |
| 排尿回数 | 1日2〜4回 |
| 1日の尿量 | 体重1kgあたり20〜30mL程度 |
| 飲水量 | 体重1kgあたり50mL程度まで |

体重4kgの猫なら、1日の尿量はおよそ80〜120mL、飲水量は200mL程度までが一つの目安になります。

重要なのは絶対値よりも**その猫自身の平常値からの変化**です。普段2回の子が5回になった、普段より明らかに塊が大きいといった変化のほうが、数字そのものより意味を持ちます。

## 「多い」「少ない」が示すもの

<VetNotice level="caution">
<p>以下は一般的に知られている傾向の整理であり、診断ではありません。当てはまる場合は自己判断せず、獣医師に相談してください。</p>
</VetNotice>

### 回数が増えた・量が減った

1回あたりの量が少ないのに何度もトイレに行く場合、膀胱に関わるトラブルが疑われることがあります。排尿時に鳴く、トイレの外で粗相するといった変化をともなうこともあります。

この状態が**まったく出ない**に進むと緊急事態になります。回数が増えているときほど、出ているかどうかの確認が重要です。

### 量も回数も増えた

飲水量が増え、それに応じて尿量も増えている場合、高齢猫では腎臓や内分泌に関わる問題が背景にあることが知られています。

このパターンは「よく水を飲むようになった＝健康になった」と誤解されやすく、**発見が遅れがちです**。シニア期に入ってから水をよく飲むようになった場合は、一度相談しておくと安心です。

### 色やにおいの変化

赤みがかっている、濃い、普段と明らかににおいが違うといった変化も、記録しておく価値があります。可能であれば写真を撮っておくと、受診時の説明が正確になります。

## 家庭での記録のとり方

受診時に獣医師が最も知りたいのは「いつから、どう変わったか」です。記憶に頼ると曖昧になるため、記録を残しておくと診察の精度が上がります。

### 手動で記録する

ノートやスマホのメモで十分です。最低限、次の3つを残します。

- 日付と排尿回数
- 固まった砂の大きさ（普段との比較で可）
- 気づいた変化（鳴く、粗相、色）

### 自動で記録する

毎日の手記録は続きません。猫が複数いる場合はそもそも誰の尿か判別できないため、記録の信頼性も落ちます。

最近の自動猫トイレには**体重センサーで個体を識別し、排尿回数と滞在時間を自動で記録する**機能を持つ機種があります。手間をかけずに平常値の蓄積ができるため、変化に気づきやすくなります。多頭飼いで個体別の把握が難しい環境ほど、この機能の価値は大きくなります。

ただしこれらは**記録のための道具であり、病気を見つけたり防いだりする医療機器ではありません**。あくまで獣医師に伝える材料が増える、という位置づけで考えてください。

機種ごとの記録機能の精度は差が大きいので、選び方は[自動猫トイレの3年総額を計算](/articles/auto-litter-box-total-cost/)とあわせて検討してください。

### 飲水量を把握する

飲水量の変化は尿量の変化より先に現れることがあります。給水器を使う場合は、目盛りのあるタイプや減った量が分かるタイプだと記録しやすくなります。

水を飲む場所が複数あると総量が分からなくなるため、記録したい時期は給水ポイントを絞るのも一つの方法です。

## 受診のタイミング

| 状況 | 対応 |
| --- | --- |
| まったく出ていない・出そうで出ない | **今すぐ受診** |
| 排尿時に鳴く、血が混じる | その日のうちに受診 |
| 回数や量の変化が2〜3日続く | 早めに受診 |
| 飲水量が明らかに増えた（シニア期） | 近いうちに相談 |
| 一時的な変化で他に異常なし | 記録して経過観察 |

迷った場合は電話で相談してください。多くの動物病院は電話で緊急度の判断をしてくれます。

## 医療費への備え

泌尿器のトラブルは再発しやすく、通院が続くことがあります。検査や処置が重なると費用はまとまった額になります。

ペット保険は通院を補償するかどうかでプランが分かれており、通院の多い疾患に備えるなら通院補償の有無が選択の軸になります。加入後に判明した既往症は補償対象外になるのが一般的なので、検討するなら健康なうちが前提です。

## まとめ

- 成猫の排尿は1日2〜4回が目安。ただし**その猫の平常値からの変化**が重要
- **まったく出ていない場合は緊急**。とくにオス猫は時間の猶予がない
- 回数が増えた、量が増えた、色が変わったは記録して獣医師に伝える
- 記録は手動でも可能だが、自動トイレの記録機能を使うと平常値が蓄積されて変化に気づきやすい
- 記録する道具は医療機器ではない。判断は必ず獣医師に委ねる

この記事は一般的に知られている情報を整理したもので、診断や治療法を示すものではありません。愛猫の健康に関する判断は、必ずかかりつけの獣医師にご相談ください。
