猫の飼育費用で唯一、事前に読めないのが医療費です。何も起きない年は年間1万円台で収まりますが、一度何かあると桁が変わります。

この記事では費用の段階と、備え方の考え方を整理します。

## 費用は段階で跳ね上がる

猫の医療費は連続的に増えるのではなく、**段階的に跳ね上がります**。

| 段階 | 費用の目安 |
| --- | --- |
| 診察のみ | 1,000〜2,000円 |
| 診察＋簡単な検査 | 5,000〜10,000円 |
| 血液検査・レントゲン・エコー | 10,000〜30,000円 |
| 麻酔を伴う処置 | 30,000〜80,000円 |
| 手術＋入院 | 100,000〜400,000円 |

診察だけなら数千円ですが、検査に進むと1万円を超え、処置が必要になると一気に数万円から数十万円になります。

**自由診療**であることも重要です。人間の健康保険のような一律の価格設定がないため、同じ処置でも病院によって金額が違います。

## よくある出費のパターン

### 年1回の予防

ワクチンと健康診断で、年間1万〜2万円程度です。これは予定できる出費なので予算に組み込めます。

### 急な通院

嘔吐や食欲不振など、数日様子を見ても改善しないケースです。検査まで進むと1回で1万〜3万円になります。年に1〜2回あっても不思議ではありません。

### 泌尿器のトラブル

猫で特に多い領域です。検査と処置で数万円、入院が必要になると十数万円。しかも**再発しやすく通院が続く**ことがあります。

排尿の異変は早期に気づけると対応が軽く済むため、日頃の記録が費用面でも効いてきます。観察の方法は[猫のおしっこの回数と量の目安](/articles/cat-urination-frequency/)で整理しています。

### 高齢期の継続的なケア

シニアになると定期的な検査や療法食が必要になることがあります。1回の金額は大きくなくても、**毎月続く**ため年間では無視できない額になります。

## 「平均」で予算を組むと足りなくなる

医療費を平均額で考えるのは危険です。理由は分布の形にあります。

多くの猫は年間数万円で収まる一方、一部で数十万円が発生します。この場合、平均値は実際に多くの人が経験する金額より高く出て、同時に**本当に備えるべき金額よりはるかに低く**なります。

つまり平均値は、どちらの目的にも使えません。

現実的なのは「最悪のケースでいくら必要か」で考えることです。手術と入院で30万円前後を見ておくと、多くのケースをカバーできます。

## 備え方は2つ

### 貯蓄で備える

毎月一定額を猫用に積み立てる方法です。保険料が無駄にならず、使わなければそのまま残ります。

ただし**積み上がる前に必要になるリスク**があります。若いうちに大きな出費が発生した場合、貯蓄額では足りません。

### ペット保険で備える

月々の保険料で、いざという時の自己負担を抑える方法です。判断の軸は3つあります。

- **通院が補償されるか** — 手術のみ補償のプランは保険料が安い反面、通院が続く疾患では使えません
- **補償割合** — 50%・70%・90%などから選びます。割合が上がるほど保険料も上がります
- **年齢による保険料の変化** — 多くの商品で高齢になるほど保険料が上がります

重要な前提として、**加入後に判明した既往症は補償対象外**になるのが一般的です。何か症状が出てから加入しても、その疾患には使えません。検討するなら健康なうちが条件になります。

## どちらが向くか

| 状況 | 向いている備え方 |
| --- | --- |
| 迎えたばかりで若い | 保険（貯蓄が積み上がる前のリスクをカバー） |
| すでに十分な貯蓄がある | 貯蓄（保険料の分だけ有利） |
| 通院が多い疾患の既往がある | 貯蓄（既往症は補償されないため） |
| 多頭飼い | 保険（同時に出費が重なるリスク） |

どちらが正解ということはなく、**手元資金と猫の年齢**で決まります。

## まとめ

- 医療費は段階的に跳ね上がる。診察のみなら数千円、手術・入院で数十万円
- 自由診療なので病院によって金額が違う
- **平均値で予算を組むと備えとして機能しない**。最悪ケースで考える
- 備えは貯蓄か保険。年齢と手元資金で選ぶ
- 保険を検討するなら**健康なうち**が前提
